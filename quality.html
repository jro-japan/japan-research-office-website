Quality framework

Practical controls designed to improve traceability, consistency and usability.

Source control

Source title, URL, publication date, access date and source type are recorded where applicable.

Data control

Names, dates, amounts, units, categories and duplicate records are checked.

Analytical control

Facts, inference, recommendations and uncertainty are clearly distinguished.

Delivery control

Scope, disclaimers, file integrity, links and client-facing language are reviewed.

Version control

GitHub, change logs and named releases support reproducibility and rollback.

Confidentiality

Project information is handled according to agreed confidentiality requirements.
